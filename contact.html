Contact

For broken links, game suggestions, corrections and general enquiries, email JohnnyDaJokergaming@gmail.com. Please include the game title and link when reporting a problem. Do not send passwords or sensitive personal information.

Suggest a browser game

Send the game's name and a direct browser URL, plus a short note about what makes it worth playing. Tell us if the game needs an account, downloadable files, keyboard or touchscreen controls, or if it only works on certain devices. We review candidate listings before marking them checked.

Report a problem

If a game opens a directory instead of the game, won't launch, has moved, or shows a browser safety warning, tell us which Vault listing you used and what happened. A screenshot can help, but please don't include private accounts or passwords.

For a copyright or ownership concern, use our rights and takedown information. You can also browse the main Vault while we review suggestions.
